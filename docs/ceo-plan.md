## The 6 gates (the spec, in one place)

Every AI agent following this protocol must pass **all six** gates before declaring a task done. The protocol is normative on these six; everything else is convention.

| # | Gate | Question | Mechanic |
|---|------|----------|----------|
| 1 | **Spec** | Is the task written as Given/When/Then acceptance criteria, not vibes? | `task.md` filled in before any code is written |
| 2 | **Scope** | Is the diff bounded — no unrequested additions? | `git diff --stat` against `task.md`'s "Out of scope" list; ≤N changed lines per existing file; no new top-level dirs |
| 3 | **Verify** | Did the agent actually RUN its code and observe pass? | Mandatory `pytest` / `phpunit` / `npm test` / `go test` exit code 0, captured in DONE.md |
| 4 | **Context** | Did the agent check its assumptions about existing code? | List every file read + the assumption it confirmed/disproved, in DONE.md |
| 5 | **Done** | Is every other gate's evidence present? | All four checkboxes above must be ticked in DONE.md |
| 6 | **Recover** | Can the agent undo its last change without manual intervention? | `git revert HEAD` (or harness-equivalent) succeeds; if mid-task breakage, agent reverts before continuing |

**Gate 6 (Recover) is non-negotiable in v0.1.** The founder's actual lived pain is "half-finished chunks" — that pain is *specifically* the failure of gate 6. A protocol without gate 6 doesn't solve the founder's problem.

## Temporal Interrogation

What an implementer (fresh agent loading this plan + future PROTOCOL.md) will hit:

| Hour | Decision needed now | Resolution |
|------|---------------------|------------|
| 1 | What are the 6 gates? | §The 6 gates above. |
| 2-3 | How strict is "scope" gate? | Loose: ≤50 changed lines per existing file, no new top-level dirs, no new files except under `src/<new-module>/` with a 1-line justification in DONE.md. |
| 4-5 | How does the agent signal pass/fail? | Canonical: DONE.md is the source of truth. Each gate has `[x]` or `[ ]`. The skill emits `STATUS: PASS` or `STATUS: FAIL gate-N` to stdout for harnesses that don't read DONE.md. |
| 6+ | What tests ship with v0.1? | `tests/test_python_example.py` runs the Python example end-to-end and asserts all 6 gates. |

**Daily 10-min journal:** while dogfooding, write `dogfood/YYYY-MM-DD.md` with: (a) which gate I most wanted to skip today, (b) which gate actually caught a bug, (c) free-form. After 5 tasks, write `dogfood/SUMMARY.md` listing gate effectiveness.

## Abort criteria for public push

Public push happens only if **all three** of the following are true:
1. **5 tasks** completed across at least 2 of {Qalam, Calora, Specboard} using the protocol.
2. At least one gate caught a real bug the founder would have shipped without it.
3. `dogfood/SUMMARY.md` says the protocol took less than 30% extra time vs no-protocol baseline.

If any of the three fails, dogfood continues for another 5 tasks before re-evaluation. **Maximum dogfood duration: 4 weeks.** If at 4 weeks still failing, kill the project.

**Public-push checklist (do these in order, no skipping):**

1. License audit (MIT, no GPL dependencies in any example).
2. Secret scan (`gitleaks` or equivalent) on every example.
3. Repo settings: branch protection on main, issue templates, `CODEOWNERS`, `LICENSE`, `SECURITY.md`.
4. First 5 issues filed under `good first issue` label (post the bounty board per Cherry-pick #6).
5. Personal email review — `.git/config` user.email matches the public-facing address or is scrubbed.

## Definitions

- **Gate** — a verifiable condition the agent must satisfy before declaring done.
- **Protocol** — `PROTOCOL.md`; normative, language-agnostic.
- **Skill** — `SKILL.md`; the harness-specific consumer (Hermes-only in v0.1).
- **Task** — a single unit of work, scoped to one feature/bug/refactor.
- **Acceptance criterion** — one Given/When/Then line in `task.md`.
- **Verify artifact** — the test run output captured in DONE.md (gate 3 evidence).
- **Implementer** — any person or agent building against this protocol.
- **Contributor** — someone filing a PR to this repo (subset of implementer).
- **Worked example** — a real coding task demonstrated end-to-end with gate evidence.
- **DONE.md** — the 6-gate checklist the agent fills in at task completion.
