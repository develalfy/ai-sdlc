## Lessons learned

1. **Never put bare identifiers in backticks inside a single `git commit -m "..."`**
   message. Bash expands them as command substitution before git sees them
   (corrupted the first attempt at commit `f348761`'s message). Fix: use
   `git commit -m subject -m body1 -m body2` so each -m string is its own
   argv element.

2. **The `_spec_helpers.py` fixture I added in Pass 3 was unused**. Dead
   fixtures are a real cost — they invite future contributors to think they
   should be used. Ponytail rung 1 says: if it's not called, drop it.

3. **PROTOCOL.md additions are cheap.** Adding a non-normative §9 (Install
   integrity) was 21 LOC and unlocked the security fix in install.sh without
   touching gate definitions. The protocol has room for "annexes" without
   triggering the gate-change rule (CONTRIBUTING.md → "gate-N-needed").

4. **The SPEC.md spec-test rabbit-hole has a sane stopping point.** I added
   per-gate structural tests for PHP + Node, plus shared helpers, plus a
   failure-modes spec-test. That's 47 tests. Going further (e.g., testing
   that PROTOCOL.md §3 wording matches the spec verbatim) would be
   rewriting the protocol — out of scope.
